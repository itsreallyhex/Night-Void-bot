# Night-Void-bot 🌙

The official Discord bot for the [Night Void server](https://discord.gg/sAakXRRudu), built to provide a unique and engaging experience for its members.

## Environment Variables

| Variable | Description |
|----------|-------------|
| `NIGHTVOID_TOKEN` | Your Discord bot token |
| `GUILD_ID` | Your Discord server ID |
>You will need create .ev file for the bot to work.

## Built With

- [discord.py](https://discordpy.readthedocs.io/) - Discord API wrapper
- [python-dotenv](https://pypi.org/project/python-dotenv/) - Environment variable management
